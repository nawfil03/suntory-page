# 🧃 Suntory Brand Pages — UI Prototypes

Front-end UI prototypes built for **Suntory** brand/product portals. The repo contains three independent pages.

---

## 📄 Pages

| Page | Path | Description |
|---|---|---|
| **Product Search** | `index.html` | Product search screen with live filtering, clear button and highlighted result cards (product name, pack details and barcode). |
| **Honeycomb Brand Layout** | `honeycomb page/index.html` | Interactive honeycomb grid of brand tiles that scale smoothly based on mouse position. |
| **Brand Resources – Schweppes** | `scherepps page/index.html` | Brand resource hub with sections for logo pack, legal & compliance docs, illustrations & icons and brand guidelines. |

## 🛠️ Tech stack

HTML5 · CSS3 · Vanilla JavaScript · Bootstrap / Google Fonts (via CDN)

## 🚀 How to use

No build step or install needed.

```bash
git clone https://github.com/nawfil03/suntory-page.git
cd suntory-page
```

Then open any page in your browser:

- `index.html` – Product Search
- `honeycomb page/index.html` – Honeycomb layout
- `scherepps page/index.html` – Schweppes brand resources

Or serve the folder locally (recommended):

```bash
npx serve .
# or
python -m http.server 8000
```

and visit http://localhost:8000.
